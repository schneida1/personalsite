    01 — The idea

    The best input is the one you already use.

    Most notes apps ask you to open them, pick a folder, and fill in a form. The fastest thing I do on my phone is send a text, so I built a notes app that works that way. Try it on the phone: switch between the app, Messages, and the Lock Screen.

    0 formstags, reminders, and events come from the text itself
    5 ways inSiri, Action button, Shortcuts, iMessage, its own number
    4 viewsFeed, Board, To-do, Calendar, one store
    02 — Decisions

    1. Syntax instead of forms.

      #tags, "remind me…", "- sub-items", and #event are parsed from plain text. The message itself sets the structure.

      Trade-offSyntax is hard to discover, so it's forgiving ("at 9am", "tomorrow 3pm", "in 30 minutes").

    2. Capture from anywhere.

      A Messages automation files any iMessage I send myself. Siri, Shortcuts, the Action button, and a Twilio number backed by a Cloudflare Worker cover the rest.

    3. Glanceable, not openable.

      Lock Screen widgets and a "Today" Live Activity update every time I text myself.

    4. Offline first, sync second.

      The phone keeps a full copy and syncs with the web in the background. Permanent IDs like N-0024 make notes easy to reference.
